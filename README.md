# Perchy

A flockmate for a lone budgie. Perchy shows a budgie on a branch, listens for your bird's calls through the microphone, and answers within half a second with real wild budgie calls: a chirp for a chirp, a phrase for a longer call. When it's quiet it calls out softly now and then, and every few minutes a real flock chatters in the distance.

Open the GitHub Pages link on a phone or tablet by the cage, tap **Wake Perchy** and allow the microphone. Everything runs in the browser; nothing is recorded or uploaded.

## Editing

`index.html` is built from the files in `src/` (page template, bird drawing and animation, app logic, and the sounds). After changing anything there, run `python3 build.py`.
